# Blinkit Sales Analysis Dashboard

## Project Overview
This project is an interactive Power BI dashboard developed to analyze Blinkit grocery sales data. It provides insights into sales performance, product categories, outlet characteristics, and customer ratings.

## Key Performance Indicators
- Total Sales
- Average Sales
- Number of Items
- Average Rating

## Dashboard Features
- Sales analysis by item type
- Sales comparison by fat content
- Outlet sales analysis by outlet size and location type
- Sales trends by outlet establishment year
- Outlet performance summary
- Interactive slicers for filtering by item type, outlet size, outlet location type, and metrics

## Tools Used
- Microsoft Power BI Desktop
- Power BI visualizations and interactive slicers

## Files
- `Blinkit_Sales_Analysis.pbix` – Power BI dashboard file
- `screenshots/dashboard.png` – Dashboard preview

## How to View
1. Download the `.pbix` file.
2. Open it using Microsoft Power BI Desktop.
3. Explore the dashboard and interact with the slicers.

## Project Objective
To analyze grocery sales data and present meaningful insights through an interactive dashboard.
